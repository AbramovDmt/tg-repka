# Telegram Mini App для загородного A-frame домика

## Концепция проекта

Telegram Mini App для загородного A-frame домика в Дмитровском районе.

Приложение НЕ заменяет площадки бронирования вроде Avito и Суточно, а дополняет их, одновременно формируя собственный прямой канал взаимодействия с гостями.

Проект объединяет:
- атмосферное представление объекта;
- удобную систему взаимодействия с гостями;
- дополнительные услуги;
- цифровой гид;
- систему повторных бронирований;
- собственный бренд загородного отдыха.

---

# Основная идея

## Avito / Суточно
Используются как:
- источник трафика;
- система доверия;
- площадка первичного бронирования;
- безопасная сделка.

## Telegram Mini App
Используется как:
- цифровой сервис отдыха;
- система сопровождения гостя;
- канал прямой коммуникации;
- инструмент повторных бронирований;
- пространство бренда.

---

# Важный принцип проекта

Система должна поддерживать ДВА сценария бронирования:

## Сценарий 1 — через Avito / Суточно
Подходит для:
- новых гостей;
- людей, которым важна безопасная сделка;
- тех, кто больше доверяет площадкам.

Логика:
1. Гость находит объявление.
2. Бронирует даты через площадку.
3. Получает подтверждение.
4. После этого получает доступ к Telegram Mini App.

---

## Сценарий 2 — прямое бронирование через Telegram Mini App
Подходит для:
- повторных гостей;
- постоянных клиентов;
- людей, которые уже доверяют месту.

Логика:
1. Гость открывает Mini App.
2. Выбирает даты.
3. Оставляет заявку.
4. Хозяин получает уведомление.
5. Подтверждает бронирование вручную.
6. Дальше согласуются детали оплаты и заселения.

Таким образом:
- новые гости могут использовать привычные площадки;
- постоянные гости могут бронировать напрямую;
- владелец постепенно формирует собственную базу клиентов.

# Пользовательские сценарии

# Сценарий А — первое бронирование через Avito

1. Пользователь находит объект через Avito или Суточно.
2. Изучает описание и отзывы.
3. Бронирует даты через площадку.
4. Получает подтверждение.
5. После брони получает ссылку на Telegram Mini App.
6. Через приложение:
   - изучает инструкции;
   - бронирует баню;
   - выбирает велосипеды;
   - получает рекомендации;
   - связывается с хозяином.

---

# Сценарий Б — повторное бронирование напрямую

1. Пользователь уже знаком с объектом.
2. Открывает Telegram Mini App.
3. Выбирает даты.
4. Отправляет заявку.
5. Хозяин получает уведомление.
6. Подтверждает бронь вручную.
7. Гость получает подтверждение и детали.
