# Brief: Telegram Mini App — A-frame домик

> Цифровое пространство загородного отдыха. Не сайт, не агрегатор — сервис для гостей конкретного домика.

---

## Принципы интерфейса

- **Нативный Telegram-стиль** — цвета, шрифты и компоненты из Telegram UI Kit
- **Кнопки минимум 44×44px** — комфортное нажатие большим пальцем
- **Минимум текста, максимум визуала** — фото говорят лучше слов
- **Русский язык** — весь интерфейс на русском
- **Одна задача на экран** — не перегружать
- **Все состояния** — loading / empty / success / error везде

---

## Навигационная модель

```
Главная (hub)
│
├── Домик
│   └── Бронирование → Подтверждение → Экран успеха
│
├── Баня
│   └── Выбор слота → Подтверждение → Экран успеха
│
├── Велосипеды
│   └── Настройка → Подтверждение → Экран успеха
│
├── Что рядом
│   └── Карточка места
│
├── Инструкции
│
└── Связь с хозяином
```

**Механика навигации:**
- Открытие любого раздела → Telegram BackButton появляется в шапке
- Нажатие BackButton → возврат на Главную (или на предыдущий экран в цепочке)
- Браузерный `history.back()` — не используется

**Назначение:** точка входа, формирует атмосферу, даёт быстрый доступ к разделам.

```

│─────────────────────────────────│

│─────────────────────────────────│
│  [ПРОВЕРИТЬ ДАТЫ]  ← MainButton │
└─────────────────────────────────┘
```

#### Элементы

| Элемент | Описание |
|---|---|
| Hero-фото | Полноширинное атмосферное фото домика, 60% высоты экрана |

#### Действия и переходы

| Действие | Переход |
|---|---|
| Тап на "Домик" | → Экран Домик |
| Тап на "Баня" | → Экран Баня |
| Тап на "Велосипеды" | → Экран Велосипеды |
| Тап на "Что рядом" | → Экран Что рядом |
| Тап на "Инструкции" | → Экран Инструкции |
| Тап на MainButton | → Экран Бронирование |

#### Состояния

- **Loading:** skeleton-заглушка статуса доступности, карточки разделов отображаются сразу (статичные)
- **Нет сети:** статус скрыт, остальное работает

### 3. Бронирование

**Назначение:** форма заявки на прямое бронирование. Для постоянных гостей.

#### Что видит пользователь

```
┌─────────────────────────────────┐
│  ← Бронирование                 │
│─────────────────────────────────│
│  ВЫБЕРИТЕ ДАТЫ                  │
│  [Календарь]                    │
│  серые = занято / зелёные = free│
│                                 │
│  Заезд: 14 июня (пт)            │
│  Выезд: 16 июня (вс)            │
│  Итого: 2 ночи                  │
│─────────────────────────────────│
│  ГОСТИ                          │
│  [−]  2 взрослых  [+]           │
│─────────────────────────────────│
│  СТОИМОСТЬ                      │
│  2 ночи × 5 000 ₽ = 10 000 ₽   │
│  Уборка: 1 000 ₽                │
│  Итого: 11 000 ₽                │
│─────────────────────────────────│
│  КОММЕНТАРИЙ (необязательно)    │
│  [Есть питомец / приедем поздно]│
│─────────────────────────────────│
│  ℹ️ Отмена за 3 дня — бесплатно │
│─────────────────────────────────│
│  ─── или ───                    │
│  [Авито]  [Суточно.ру]          │
│─────────────────────────────────│
│  [ОТПРАВИТЬ ЗАЯВКУ] ← MainButton│
└─────────────────────────────────┘
```

#### Элементы

| Элемент | Описание |
|---|---|
| Календарь | Месячный вид, занятые даты серые, свободные — дефолт, выбранные — accent-цвет Telegram |
| Даты заезда/выезда | Показываются после выбора в календаре |
| Счётчик гостей | Кнопки − / + , диапазон 1–4 |
| Блок стоимости | Разбивка: ночи × цена + уборка = итого |
| Поле комментария | Однострочный ввод, необязательное |
| Политика отмены | Текст до кнопки (не после) |
| Ссылки на площадки | Вторичные кнопки "Авито" и "Суточно.ру" |
| MainButton | "Отправить заявку" |

#### Действия и переходы

| Действие | Переход |
|---|---|
| Выбор дат в календаре | Обновляет блок стоимости |
| Тап "Авито" / "Суточно" | `openLink()` → внешний браузер |
| Тап MainButton "Отправить заявку" | → Экран подтверждения заявки |
| BackButton | → Домик |

#### Состояния

- **Даты не выбраны:** MainButton неактивна (серая)
- **Все выбранные даты заняты:** сообщение "В эти даты домик занят, выберите другие"

#### Элементы

| Элемент | Описание |
|---|---|
| Фото бани | Полноширинное, фиксированная высота 200px |
| Параметры | Вместимость + цена/час + минимальное время |
| Выбор даты | Горизонтальная лента из 14 дней (сегодня + 13 дней) |

| Действие | Переход |
|---|---|

| Выбор длительности | Пересчёт цены и времени окончания |
| MainButton | → Подтверждение (дата, слот, цена) → Экран успеха |
| BackButton | → Главная |

#### Состояния

- **Слоты загружаются:** skeleton-карточки слотов
- **Все слоты заняты:** "На эту дату все слоты заняты, выберите другой день"
- **Слот не выбран:** MainButton неактивна

### 9. Экран успеха (системный)

**Показывается после:** отправки заявки на домик / бронирования бани / заказа велосипедов.

#### Что видит пользователь

```
┌─────────────────────────────────┐
│                                 │
│         ✓                       │
│                                 │
│   Заявка отправлена!            │
│                                 │
│   Хозяин свяжется с вами        │
│   в течение часа                │
│                                 │
│   [На главную] ← MainButton     │
│                                 │
└─────────────────────────────────┘
```

Текст меняется в зависимости от действия:
- Бронирование домика: "Заявка отправлена! Хозяин свяжется в течение часа"
- Баня: "Баня забронирована! Ждём вас 16 июня в 16:00"
- Велосипеды: "Велосипеды заказаны! Заберите у хозяина при заезде"

**После показа этого экрана — бот присылает подтверждение в Telegram гостю.**

### HapticFeedback

- Выбор слота бани → `impact(medium)`
- Выбор даты в календаре → `impact(light)`
- Успешное бронирование → `notification(success)`
- Ошибка / занято → `notification(error)`

### Темы

- Поддержка light и dark через `Telegram.WebApp.colorScheme`
- Все цвета — из Telegram CSS-переменных (`var(--tg-theme-bg-color)` и др.)
