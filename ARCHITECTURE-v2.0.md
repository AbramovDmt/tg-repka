## Стек и деплой

- Vanilla JS + HTML + CSS, без сборки (no build step, no npm-зависимостей в проде)
- Telegram Web App SDK (`tg.initDataUnsafe`, `MainButton`, `BackButton`, haptics)
- Хостинг: Vercel, автодеплой с ветки `main` папки `tg-app/`
- Backend: Vercel serverless-функции в `tg-app/api/`

## Структура файлов

```
tg-app/
├── index.html        — точка входа, подключает Telegram SDK + Google Fonts (Playfair Display 600/700)
├── css/styles.css     — все стили, CSS-переменные тем (light/dark), ~2200 строк
├── js/data.js         — весь контент: цены, тексты, слоты, места (APP_DATA)
├── js/app.js          — роутер, экраны (screens), обработчики, Telegram SDK — ~2000 строк
├── api/
│   ├── calendar.js    — живой парсинг ICS-календарей Avito + Sutochno.ru → занятые даты
│   └── send-order.js  — отправка заявки хозяину в Telegram (только пересылка, ничего не хранит)
└── CLAUDE.md          — гайд для разработчика (частично устарел, см. секцию "Расхождения" ниже)
```

## Дизайн-токены (текущее состояние v2.0)

### Цвета (`:root` в `styles.css`, светлая/тёмная тема через `body.dark`)
- Фон: `--tg-bg: #F7F4EF` (тёплый крем), `--tg-secondary-bg: #EEE9E1`
- Текст: `--tg-text: #1C2B1E`, `--tg-hint: #6E8064`
- Акцент (основной, "природный/лесной"): `--accent: #3C5948`
- Янтарный (тёплый, для бани/предупреждений): `--amber: #7A4728`
- Терракота (акцент заголовков, добавлено в этой сессии): `--terracotta: #C2694A`
- Тематизация по экранам: `.sauna-screen` — оранж `#E05A20`, `.bikes-screen` — бирюза `#20A8C0`, `.nearby-screen` — зелень `#7AC840` (переопределяют `--accent`/`--amber` только внутри своего экрана)
- Карточки: `--glass-bg` (полупрозрачный + `backdrop-filter: blur(18px)`), `--glass-amber-bg` — тёплый вариант для бани и карточки "Правила"

### Типографика
- Основной текст: системный шрифт (`-apple-system, Segoe UI, Helvetica, Arial`)
- Заголовки бренда (`--font-display`): **Playfair Display**, подключён в `index.html` (веса 600/700, **без italic** — отличие от лендинга, где используется italic 700 для логотипа)
- Используется в: `.house-name`, `.onboarding-title`

### Форма и глубина
- Радиусы: `--r-sm: 8px`, `--r-md: 14px`, `--r-lg: 18px`, `--r-xl: 24px` — крупные, "app-native" скругления
- Тени: мягкая тень + внутренний блик (`--card-shadow`), стекло (blur) — не плоский стиль
- Отступы: `--sp-xs/sm/md/lg/xl` = 4/8/16/24/32px

### Иконки
Свои инлайн-SVG (не библиотека), stroke-width 1.7, линейный стиль — визуально близко к lucide-react лендинга, но независимый набор путей.

## Бэкенд / интеграции — что реально работает, а что нет

- **Календарь занятости (`api/calendar.js`)** — реально работает: парсит ICS-фиды Avito и Sutochno.ru на лету, отдаёт занятые даты. Кэш 1 час.
- **Отправка заявки (`api/send-order.js`)** — реально работает, но **только пересылка**: формирует текст и шлёт хозяину в Telegram через Bot API. Ничего не сохраняет, гостевой базы нет.
- **База гостей / повторные уведомления** — **не реализовано**. План есть в `BACKEND-PLAN.md` (таблицы `guests`/`bookings` в Supabase), но по итогам юридического разбора (см. `PROJECTS.md` в Fedot) решено переносить на self-hosted Postgres на Beget VPS — это отдельная будущая работа, не часть v2.0.
- **Уведомления гостям о статусе брони** — по `tg-app/CLAUDE.md` всё ещё симулируются (Success-экран), реальной отправки гостю нет.
