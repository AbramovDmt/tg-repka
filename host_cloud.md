# Хостинг vs Облако — итоги обсуждения

## Контекст

Проект: Telegram Mini App для аренды A-frame домика (СНТ Репка).
Хозяин объекта — Сергей, у него уже есть аккаунт на Beget (тариф Start, сервер fedin8j4.beget.tech).
Оплата должна быть рублями, российскими сервисами.

---

## Хостинг vs Облако — в чём разница

**Хостинг (shared)** — загружаешь файлы, сервер уже настроен. Beget сам занимается Node.js, SSL и т.д. Подходит для статических сайтов (HTML/CSS/JS). Дёшево, никакого Linux не нужно.

**Облако (VPS)** — арендуешь виртуальный компьютер. Нужно самому ставить Node.js, nginx, настраивать безопасность. Для новичка сложнее, но даёт полный контроль.

---

## Что куда идёт

```
Beget хостинг  →  лендинг Репки
               →  TMA приложение (tg-app/) ← тоже статика!
               →  третий сайт (без бэкенда)

Beget Cloud    →  Node.js бэкенд + Telegram бот
(VPS)             (~330 ₽/мес, нужен только когда дойдём до бэкенда)

Supabase       →  база данных PostgreSQL (бесплатно)

ЮКасса         →  приём платежей (% от транзакции)
```

**Важно:** TMA приложение — это статика, ему VPS не нужен. VPS нужен только для Node.js сервера (бот + API).

---

## Почему не Railway (оригинальный план)?

Railway — американский сервис, оплата картой РФ затруднена. Заменяем на Beget Cloud VPS — Сергей уже там, оплата рублями, всё в одном кабинете.

---

## База данных — Supabase vs Beget Cloud БД

Оба дают PostgreSQL. Остаёмся на Supabase бесплатном тарифе:

| | Supabase | Beget Cloud БД |
|--|---------|----------------|
| Цена | бесплатно | ~1 000 ₽/мес |
| Карта | не нужна | рублями |
| Для этого проекта | хватает с запасом | избыточно |

Лимиты Supabase free: 500 МБ хранилища, 2 проекта. Для нескольких десятков броней в месяц — более чем достаточно.

**Нюанс:** бесплатный проект засыпает после 7 дней без активности. Первый запрос после паузы чуть медленнее — не критично для аренды домика.

## Итоговая экономика

| Сервис | Оплата | Сумма |
|--------|--------|-------|
| Beget хостинг | уже есть у Сергея | ~0 |
| Beget Cloud VPS | рублями | ~330 ₽/мес |
| Supabase | не нужна | бесплатно |
| ЮКасса | % от брони | по факту |

**Единственная статья расходов на инфраструктуру — VPS ~330 ₽/месяц.**
